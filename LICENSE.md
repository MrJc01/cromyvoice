# Licença MyVoice

Este projeto é Open Source e pode ser utilizado livremente para fins pessoais e profissionais, desde que respeitadas as condições abaixo relacionadas ao uso comercial e revenda.

## 1. Uso Permitido
O **MyVoice** pode ser utilizado sem custos em:

- **Projetos Pessoais:** Estudos, ferramentas utilitárias privadas, uso em streams, calls, reuniões diárias ou portfólios.
- **Projetos Profissionais/Empresas:** Uso do MyVoice como ferramenta de acessibilidade/comunicação ou integração do sistema como um componente auxiliar em aplicações maiores.

**Exemplos de Uso Permitido:**
- Um criador de conteúdo que usa o MyVoice para interagir com o chat ou equipe durante transmissões ao vivo.
- Uma empresa que utiliza o MyVoice como ferramenta interna para geração de comunicados rápidos, painéis de RH ou para funcionários com necessidades de acessibilidade na fala.
- Um software que utiliza o motor do MyVoice sob o capô de forma secundária para ler textos aos usuários.

## 2. Restrições de Comercialização e Revenda (Serviços Pagos)
É estritamente proibida a revenda ou comercialização do **MyVoice**, ou de produtos derivados dele, onde a geração e injeção de voz (Virtual Mic/TTS) do MyVoice seja o fator principal ou o foco central da aplicação, **desde que seja um serviço ou produto pago**, sem uma licença comercial expressa.

**Uso Livre e Open Source:** Se o seu projeto for totalmente gratuito e de código aberto (Open Source), você pode utilizar o MyVoice como foco principal sem restrições.

**Exemplos de Uso Restrito (Requer Licença):**
- Criar um SaaS de Text-to-Speech (TTS) ou dublagem **PAGO** cujo principal diferencial produtivo seja provido pelo pipeline de integração do MyVoice.
- Vender um Software de Desktop ou "Soundboard" **PAGO** que sirva principalmente como uma interface comercial para as funções nativas e roteamento do MyVoice.
- Disponibilizar uma API paga de processamento de voz focada especificamente em geração de áudio virtual usando este motor.
